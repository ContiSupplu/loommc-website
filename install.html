Your Mix is Downloading

Follow the steps below to install the .mrpack file in your launcher.

1

Open Loom Launcher

Launch the Loom application. If you don't have it yet, download it here.

2

Import .mrpack

Go to your Library and click the Import button (or drag-and-drop the .mrpack file into the window).

3

Select your downloaded file

Navigate to your Downloads folder and select the .mrpack file you just downloaded.

4

Play!

Loom will automatically install the mods, configure the loader, and set up the instance. Just hit Play when it's ready.

Tip: You can also clone mixes directly from the Mixes tab in Loom — no .mrpack download needed!
1

Open Prism Launcher

Launch Prism Launcher on your computer.

2

Add Instance

Click Add Instance in the toolbar, then select the Import tab on the left sidebar.

3

Browse for the file

Click Browse and navigate to your Downloads folder. Select the .mrpack file.

4

Install & Launch

Click OK and Prism will download all mods and set up the instance. Double-click the new instance to play.

1

Open MultiMC

Launch MultiMC on your computer.

2

Add Instance → Import

Click Add Instance, then select Import from zip in the dialog.

3

Select the .mrpack file

Browse to your Downloads folder and select the .mrpack file.

4

Launch

MultiMC will set up the modded instance. Click Launch when ready.

1

Extract the .mrpack

Rename the .mrpack file to .zip and extract it with any archive tool (7-Zip, WinRAR, etc.).

2

Read modrinth.index.json

Open the modrinth.index.json file inside. It lists all mods, their versions, and download URLs.

3

Download each mod

Visit the download URLs listed in the files array and save each .jar to your Minecraft mods folder.

4

Install the correct loader

Check the dependencies section for the required mod loader (Fabric/Forge/NeoForge/Quilt) and Minecraft version. Install accordingly.

Manual installation is not recommended. Use a compatible launcher for the best experience.
