Everything Loom can do

Built for players who actually mod their game.

Loom isn't just a launcher — it's a full toolkit. AI crash diagnosis, in-game overlays, Bedrock support, recording, Spotify, and mod management that doesn't get in your way. Here's every feature, explained.

01

Loomie AI

Your built-in AI assistant, powered by Google Gemini. Loomie doesn't just answer questions — it reads your crash logs, pinpoints the broken mod, removes it, and verifies the fix. You can also use it to install mods, tweak settings, or ask anything about Minecraft, all through a chat interface.

Crash Diagnosis

When Minecraft crashes, Loomie reads the full crash log and matches it against 13+ known patterns — Mixin injection failures, missing dependencies, duplicate mods, out-of-memory errors, class loading conflicts, and more. It identifies the specific mod at fault, removes or replaces it, then re-launches to verify the fix actually worked.

Launcher Actions via Chat

Loomie has 16 function-calling tools wired into the launcher. Ask it to install Sodium, create a new 1.21 Fabric instance, remove a broken mod, or adjust your RAM — it calls the right function and does it for you, no menus required.

In-Game Overlay

Loomie works inside Minecraft too. A Fabric mod renders an overlay so you can ask questions, get help with a build, or diagnose a crash — all without alt-tabbing. Supported on 1.21 and 1.21.1.

Smart Retry & Fallback

If Google's API returns a 503 or 429, Loomie automatically retries up to twice. If the primary model (gemini-2.5-flash) keeps failing, it falls back to gemini-2.0-flash so your request still goes through.

02

Dynamic Island

A floating HUD bar that lives at the top of your screen — in the launcher and as a transparent in-game overlay. It surfaces the right info at the right time: download progress, the song playing on Spotify, your server's status, or a crash alert with a one-click fix. When nothing is happening, it collapses out of sight.

Contextual States

The island morphs depending on context: launch progress with a real percentage bar, Spotify album art and track name with playback controls, a green indicator when the game is running, or an expanded crash alert with details and a "Fix with Loomie" button.

In-Game Overlay

A Fabric mod renders the island on top of your Minecraft window as a transparent, click-through overlay. You see your music, downloads, and alerts without leaving the game. Supported on Minecraft 1.21 and 1.21.1.

Crash Alerts

When Minecraft crashes, the island expands immediately with the error and a one-click "Fix with Loomie" button. Loomie reads the crash log, identifies the problem, and offers an automatic fix — all without you opening a single file.

03

Java + Bedrock

Play both editions from one launcher. Loom manages your Java instances with full mod support, and detects your Bedrock installation for world browsing, addon management, and direct launching. No other third-party launcher supports both editions.

Bedrock World Browser

Browse your Bedrock worlds inside Loom — see world names, sizes, and last-played dates. Launch directly into any world or manage your addon packs from the same interface.

Add-On Browser & Smart Downloads

Search for Bedrock add-ons across MCPEDL, CurseForge, ModBay, and Planet Minecraft. Loom auto-detects .mcaddon and .mcpack files and installs them directly — no manual file juggling.

Marketplace Ad Blocker

Toggle the built-in Marketplace ad blocker to remove promotional content from your Bedrock experience. One switch in the Bedrock page — no external tools needed.

04

Mods & Modpacks

Full Modrinth integration with one-click installs and automatic dependency resolution. Loom supports all four mod loaders — Fabric, Forge, NeoForge, and Quilt — and ships with smart features like Mod Vault deduplication and auto-installed performance mods.

One-Click Install

Search Modrinth from inside Loom, hit install, and Loom picks the right version for your game version and loader. Dependencies are resolved automatically — if a mod requires Fabric API or Architectury, Loom installs those too.

Modpack Import

Install Modrinth modpacks with one click, or drag-and-drop a local .mrpack file. Loom creates a new instance, downloads every mod and config, and you're ready to play.

Mod Vault

Loom uses hard-link deduplication to share identical mod files across instances. If 5 instances use Sodium, it's stored once on disk. This can save gigabytes of storage on heavily modded setups — check your savings in Settings.

Auto Performance Mods

When you create a new Fabric instance, Loom can auto-install Sodium, Lithium, and Iris — the essential performance trio. Loomie keeps them updated and resolves any conflicts with your other mods automatically.

05

Instance Management

Create, customize, duplicate, trash, recover, and migrate instances — all from one place. Each instance is a self-contained Minecraft installation with its own version, mods, worlds, and JVM settings. Loom gives you full control without making you touch a file explorer.

Create & Customize

Pick a version from a smart picker grouped by major release, with search and recommended versions highlighted. Customize your instance name, card color (12 presets + any hex), background image, custom icon, memory allocation (1–16 GB), and JVM arguments.

Duplicate & Copy

Clone an instance to create an exact copy — mods, configs, worlds and all. You can also copy instances across different profiles, making it easy to share setups between accounts.

Trash & Recovery

Deleted instances go to a soft-delete trash with an expiration timer. Changed your mind? Restore any trashed instance with one click. No more accidental data loss.

File Explorer & Migration

Every instance has a built-in file explorer — browse, rename, delete, and copy files without leaving Loom. Switching launchers? Import your full setup from Prism, MultiMC, CurseForge, ATLauncher, or the vanilla launcher.

06

Media & Entertainment

Loom puts Spotify, screen recording, a video editor, and Twitch right inside the launcher — and into the game via the overlay. No more alt-tabbing to skip a song or check if your favorite streamer went live.

Spotify Integration

Control playback, see album art, read lyrics — all from the launcher and the in-game Dynamic Island overlay. Connect via OAuth2 in Settings; your credentials are encrypted locally.

Recording & Clip Editor

Record gameplay via FFmpeg with a hotkey. Loom also captures screenshots on demand. Then open the built-in editor to trim clips, apply speed ramps (0.25×–4×), add text overlays, or merge multiple clips into one video.

Gallery

All your screenshots and recordings live in one gallery page. Browse, preview, edit, and share directly to Discord via webhook — without hunting through folders on your desktop.

Twitch Integration

Follow your favorite Minecraft streamers and get live notifications when they go online. Watch Twitch directly inside Loom or through the in-game overlay.

07

Performance

Loom squeezes every frame out of your hardware. Optimized JVM flags, smart caching, and auto-installed performance mods work together to get Minecraft running faster than vanilla — especially on repeat launches.

JVM Flag Presets

Loom ships with optimized JVM flag presets (including Aikar's G1GC flags) tuned specifically for Minecraft. Pick a preset or write your own custom args — per instance or globally.

Cache & Skip

After the first launch, Loom caches baked models and textures to disk. On subsequent launches, it loads from cache instead of rebuilding — shaving 2–5 seconds off your load time every single time you play.

Memory & System Tuning

Choose from memory presets (1–16 GB) or set a custom value. Loom can also switch to a High Performance power plan during gameplay, set process priority, and optionally exclude the game folder from Windows Defender scanning.

08

Privacy & Security

Your data stays on your machine. Loom encrypts sensitive credentials, offers region-based privacy controls, and keeps your configs in sync across instances without cloud uploads.

Privacy Mode

Enable Privacy Mode for region-based compliance controls. Loom adjusts data handling based on your region, giving you fine-grained control over what's stored and what's sent.

Encrypted Credentials

API keys, OAuth tokens, and proxy credentials are encrypted locally using your system's credential store. They never leave your machine in plain text.

File Sync

Keep configs, mods, and resource packs synchronized across instances with bi-directional sync groups. Loom uses file-level hashing so only changed files are copied — no cloud, no uploads, just local consistency.

09

Quick Servers Coming Soon

Host a Minecraft server in two clicks. No port forwarding, no terminal commands, no queues. Pick your game mode, choose a plan, share the link — and your friends join instantly. Bedrock crossplay included.

One-Click Hosting

Click "Create Server," pick a version and game mode, and your server spins up. No port forwarding, no router configuration — Loom handles networking with tunneling so anyone can join with a link.

Plugin Browser & File Manager

Browse and install server plugins via Modrinth integration. Manage server files, configs, and world data with a built-in file manager — no FTP clients or SSH needed.

Bedrock Crossplay

Toggle Bedrock crossplay with a single switch. Java and Bedrock players can join the same server — Loom configures GeyserMC automatically behind the scenes.
