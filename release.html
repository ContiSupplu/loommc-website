LATEST RELEASE

Loom v1.6.4 — Netherite

June 2, 2026

What's New

  • Improved AI Fixes — Loomie now retries on overloaded models and automatically falls back to a secondary model so you never get stuck. Improved
  • Smarter Crash Diagnosis — Loomie recognizes 13+ crash patterns including Mixin conflicts, missing dependencies, duplicate mods, and out-of-memory errors. New
  • Bedrock Edition — Play Bedrock from the same launcher. Browse worlds, install addons from MCPEDL and CurseForge, block Marketplace ads. New
  • Dynamic Island — See downloads, Spotify playback, and crash alerts in a floating bar — even while in-game. New
  • In-Game Loomie — Talk to Loomie while playing via the Fabric mod overlay. Ask questions, get help, without leaving the game. New
  • Recording + Video Editor — Record gameplay, save replays from a rolling buffer, then trim, speed-ramp, add text, and merge clips. New

Fixes & Improvements

  • Gemini API Resilience — 2 retries on 503/429 errors with automatic fallback from gemini-2.5-flash to gemini-2.0-flash. Improved
  • Performance Mod Conflicts — Loomie now automatically removes perf mods that conflict with modpack mods instead of the other way around. Fix
  • Mod Removal — The remove_mod tool now blacklists removed mods so the auto-installer doesn't re-add them. Improved
  • Bedrock Ad Blocker — Toggle in the browser toolbar to block Marketplace ads on MCPEDL and other addon sites. New
