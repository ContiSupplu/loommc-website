Loom v1.6.6 — Netherite

June 2, 2026

What's New in v1.6.6

  • Improved AI Fixes — Loomie now retries on overloaded models and automatically falls back to a secondary model so you never get stuck. Improved
  • Smarter Crash Diagnosis — Loomie recognizes 13+ crash patterns including Mixin conflicts, missing dependencies, duplicate mods, and out-of-memory errors. Improved
  • Gemini API Resilience — 2 automatic retries on 503/429 errors with fallback from gemini-2.5-flash to gemini-2.0-flash. New
  • Performance Mod Conflicts — Loomie now automatically removes perf mods that conflict with modpack mods instead of the other way around. Fix
  • Mod Removal Blacklisting — Removed mods are now blacklisted so the auto-installer doesn't re-add them. Improved
