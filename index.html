Features

Loomie AI

Crash mid-game? Loomie reads the log, identifies the broken mod, and tells you exactly how to fix it. Powered by Gemini 2.5 Flash. No more pasting stack traces into Discord and waiting for someone to reply.

Smart Library

Every instance, mod, and version in a single sidebar. Filter by loader, sort by last played, clone an instance in two clicks. Your library adapts as your modding setup grows.

Quick Servers

Two clicks to host. Share a link with friends. No port forwarding, no Aternos queues, no waiting. Multiplayer should be that simple.

Dynamic Island

A floating HUD borrowed from Apple — tracks download progress, launch state, and server status. Shows up when something is happening, disappears when it is not.

Built-in Performance

Sodium, Lithium, Iris, and a tuned mod stack come pre-installed on every instance. Loom keeps them updated and resolves version conflicts automatically.

Java + Bedrock

Both editions in the same launcher, the same library, the same UI. Switch between Java and Bedrock without switching apps.
