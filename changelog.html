Changelog

Every update from Cobblestone to Netherite.

v1.6.4 "Netherite" Latest

Jun 2, 2026

  • Improved AI Fixes — Loomie retries on overloaded models and automatically falls back to a secondary model
  • Smarter Crash Diagnosis — Loomie recognizes 13+ crash patterns including Mixin conflicts, missing dependencies, duplicate mods, and out-of-memory errors
  • Gemini API Resilience — 2 automatic retries on 503/429 errors with fallback from gemini-2.5-flash to gemini-2.0-flash
  • Performance Mod Conflict Fix — Loomie now removes perf mods that conflict with modpack mods instead of the other way around
  • Mod Removal Blacklisting — Removed mods are blacklisted so the auto-installer doesn't re-add them
